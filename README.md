# Mi Perrito - Mascota Virtual 🐶

¡Bienvenido a "Mi Perrito"! Una adorable mascota virtual construida exclusivamente con HTML5, CSS3 y Vanilla JavaScript.

## 🚀 Cómo jugar (Localmente)

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Haz doble clic en el archivo `index.html` para abrirlo en tu navegador web favorito (Chrome, Firefox, Edge, Safari).
4. ¡Disfruta cuidando a tu perrito!

## 🌐 Publicar en GitHub Pages

Para compartir tu mascota con el mundo:
1. Crea un repositorio en tu cuenta de GitHub.
2. Sube todos los archivos y carpetas de este proyecto al repositorio.
3. Ve a **Settings** (Configuración) de tu repositorio.
4. En el menú lateral izquierdo, haz clic en **Pages**.
5. En la sección *Source*, selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
6. Guarda los cambios. GitHub te proporcionará un enlace web (ej. `https://tu-usuario.github.io/tu-repositorio/`) en unos minutos.

## 🛠️ Tecnologías utilizadas

- **HTML5:** Estructura de la aplicación.
- **CSS3:** Estilos, colores pastel, diseño responsive y animaciones kawaii.
- **JavaScript (Vanilla):** Lógica del juego, interacción y guardado de estado en `localStorage`. No se utilizaron frameworks ni librerías externas.

## 🎮 Funcionalidades

- **Habitación principal:** Acaricia a tu perrito para hacerlo feliz y observa sus barras de estado.
- **Baño:** Interactúa con la esponja para bañar a tu mascota y dejarla reluciente.
- **Vestuario:** Ponle gorras, gafas y corbatines. ¡Los accesorios se guardan!
- **Parque de juegos:** Lanza la pelota y mira cómo tu perrito corre a buscarla.
- **Dormir:** Cuando tu mascota esté cansada, llévala a su cama para que recupere energía.
- **Guardado automático:** Tus avances se guardan en el navegador automáticamente.

¡Espero que disfrutes mucho de tu nueva mascota virtual!
